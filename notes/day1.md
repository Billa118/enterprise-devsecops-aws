# Day 1 - AWS Account Setup

## Objective

Set up a secure AWS account and prepare the project.

## Tasks Completed

- Created AWS Free Tier account
- Logged into AWS Console
- Enabled MFA for Root User
- Created IAM Admin User (devops-admin)
- Enabled Billing Access
- Enabled Free Tier Monitoring
- Created GitHub Repository
- Created Project Folder Structure
- Verified AWS CLI, Git and Homebrew installation

## Tools Used

- AWS Console
- IAM
- Billing & Cost Management
- GitHub
- AWS CLI
- Git
- Homebrew

## Outcome

AWS account is secure and ready for the DevSecOps project.
